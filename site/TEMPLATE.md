# Template provenance

Adapted from [areimel/kojima-astro-template](https://github.com/areimel/kojima-astro-template), revision `c04f0740a76e144b672f442b0dbd4dc1b4a3952d`.

The original Kojima palette, typography, square geometry, and instrument-panel visual language are retained. `src/styles/kojima.css` retains the template's theme tokens and core type rules. Local DM Sans fonts are retained from the template, subset to Latin and converted to woff2 (the SIL Open Font License notice stays embedded in each font file's name table). The original MIT license is preserved in `LICENSE`; the upstream template credits shadcnblocks Mainline.

Corporate intelligence pages, forms, blog content, visual laboratories, stock assets, and unused React/shadcn dependencies were omitted. The coffee-term layouts, terminal preview, documentation, and project assets replace those demonstrations.
