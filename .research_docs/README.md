# Research docs

Reference material for AI agents working on this template. Facts were checked against the installed
packages (Ink 8.0.0, React 19, ink-testing-library 4); anything not checked is marked unverified.

| File                           | Read it when                                                            |
| ------------------------------ | ----------------------------------------------------------------------- |
| `ink-8-quick-reference.md`     | You need a component prop, hook signature or `render()` option          |
| `ink-layout-scroll-overlay.md` | Building layouts, scroll views, long lists, dialogs or borders          |
| `ink-input-focus.md`           | Handling keys, modal input, text entry, or writing keys in tests        |
| `ink-testing-and-pitfalls.md`  | Writing tests, or hitting a TypeScript / xo error you do not understand |
